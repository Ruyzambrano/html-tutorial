1Semantic layout

A page built only from <div> elements means nothing to a screen reader or search engine. Semantic elements describe the role of each region: <header>, <nav>, <main>, <article>, <section>, <aside> and <footer>.

Use <main> once per page. Use <article> for content that could be shared on its own, and <section> for a themed group, ideally with a heading.

2Accessibility basics

Accessible HTML works for people using screen readers, keyboards and voice control. Most of it comes from using the right element: a real <button> is focusable and responds to Enter and Space, a styled <div> is not.

Other essentials: meaningful alt text, a logical heading order, a lang attribute on <html>, and <label> on every form control. Use aria-label only when there is no visible text to point to.

Result
Rule of thumb: if you can do it with a native element, do it. ARIA attributes are a patch for when you cannot.

3Forms in depth

Modern inputs give you validation and mobile keyboards for free. Useful type values include email, url, number, date, range, color and password. Validate with required, min, max, minlength and pattern.

Group related controls in a <fieldset> with a <legend>, and offer suggestions with <datalist>.

HTML
Result
Browser validation is a convenience, not security. Always validate again on the server.

4Figures and media

<figure> and <figcaption> pair content with a caption. For audio and video use <audio> and <video> with the controls attribute, and offer fallback sources and text.

5Built-in interactive elements

Some interactivity needs no JavaScript at all. <details> and <summary> make a collapsible section, <progress> and <meter> show values, and <dialog> creates a modal (opening it dynamically does need a little JavaScript, which page 4 covers).

6Metadata and SEO

The <head> is invisible to visitors but vital to browsers, search engines and social sites. This one is read-only because it shows what goes in a real page's head rather than something you can preview.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Clear, specific page title</title>
  <meta name="description" content="One or two sentences shown in search results.">
  <link rel="icon" href="/favicon.ico">
  <link rel="stylesheet" href="styles.css">
  <meta property="og:title" content="Title for social sharing">
  <meta property="og:image" content="https://example.com/preview.png">
</head>
Every page should have a unique <title> and description. Together with good headings and semantic HTML, that covers most of the basics of on-page SEO.
