1What is HTML?

HTML (HyperText Markup Language) is the language that gives web pages their structure. It tells the browser what each piece of content is: a heading, a paragraph, a link, an image.

You write HTML using elements. Most elements have an opening tag, some content, and a closing tag:

3Headings and text

Headings run from <h1> (most important) to <h6>. Use <p> for paragraphs, <strong> for bold importance and <em> for emphasis.

Pick headings for meaning, not size. Use one <h1> per page and step down in order.

4Links and images

The <a> element creates a link using the href attribute. The <img> element shows an image using src, and alt describes it for people who cannot see it.

8Next steps

You now know the building blocks. Here is a quick reference and where to go next.

ElementUse it for
<h1> to <h6>Headings
<p>Paragraphs
<a>Links
<img>Images
<ul>, <ol>, <li>Lists
<table>Tabular data
<form>, <input>User input

HTML on its own looks plain. The usual next step is CSS for styling, then JavaScript for behaviour. The MDN Learn web development course is a good free place to continue.
