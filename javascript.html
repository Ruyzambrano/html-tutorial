1What is JavaScript?

HTML gives a page structure, CSS styles it, and JavaScript makes it do things: respond to clicks, update content, validate input. It goes inside a <script> element, usually at the end of <body>.

console.log() prints a value for debugging. In these examples it prints into the green box under the result. In a real browser you would see it in the developer tools console (F12).

2Variables and data types

Store values with const (cannot be reassigned) or let (can be). Prefer const unless you need to change the value. The common types are strings, numbers, booleans, arrays and objects.

JavaScript
Result
Backticks create template literals, which let you embed values with ${...}. Arrays count from zero, so skills[0] is the first item.

3Functions and conditions

A function is a reusable block of code. if and else choose between paths based on a condition. Compare values with === (strict equality), <, > and combine with && (and) or || (or).

JavaScript
Result
Always use === rather than ==. The strict version does not quietly convert types, which avoids surprising bugs.

4Arrays and loops

Loops repeat work. for...of visits each item in an array. For transforming data, map builds a new array from the old one and filter keeps only items that pass a test.

JavaScript
Result
map, filter and reduce do not change the original array. They return a new value, which makes code easier to reason about.

5Changing the page (the DOM)

The browser turns your HTML into a tree of objects called the DOM. JavaScript can find elements with document.querySelector() and change their text, attributes and styles.

HTML + JavaScript
Result
Use textContent to insert plain text. Avoid innerHTML with untrusted input, because it can open the door to cross-site scripting attacks.

6Responding to events

Events are things that happen: a click, a key press, a form submission. Attach a handler with addEventListener, and the function runs each time the event fires.

HTML + JavaScript
Result
Handlers receive an event object. event.target is the element that triggered it.
