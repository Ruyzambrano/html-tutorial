Cheat sheet

A quick reference for the HTML, CSS and JavaScript from the tutorials. Type to filter.

HTMLCSSJavaScript

HTML

Page structure

<!DOCTYPE html>Declares an HTML5 document. Always the first line.
<html lang="en">Root element. lang helps screen readers and translation.
<head>Information about the page, not shown on it.
<body>Everything visitors see.
<title>Text on the browser tab. Unique for every page.
<meta charset="UTF-8">Character encoding. Put it first in the head.
<meta name="viewport" ...>Makes the page scale properly on phones.
<link rel="stylesheet" href="a.css">Loads a CSS file.
<script src="a.js"></script>Loads a JavaScript file.

Text

<h1> to <h6>Headings, most to least important. One h1 per page.
<p>Paragraph.
<strong> / <em>Strong importance (bold) / emphasis (italic).
<br>Line break.
<hr>Thematic break, drawn as a line.
<blockquote> / <q>Block quotation / inline quotation.
<code> / <pre>Inline code / preformatted block that keeps whitespace.
<span> / <div>Generic inline / block containers with no meaning.

Links, images and media

<a href="url">Link. Add target="_blank" rel="noopener" for a new tab.
<img src="a.png" alt="...">Image. alt is required for accessibility.
<figure> / <figcaption>Content with a caption.
<audio controls>Audio player.
<video controls>Video player.
<iframe src="url">Embeds another page.

Lists and tables

<ul> / <ol> / <li>Bullet list / numbered list / list item.
<dl> <dt> <dd>Description list: term and definition.
<table>Table container.
<thead> <tbody> <tfoot>Table sections.
<tr>Table row.
<th> / <td>Header cell / data cell.
colspan / rowspanMake a cell span several columns or rows.

Forms

<form action method>Groups form controls.
<label for="id">Names a control. Matches the input's id.
<input type="...">text, email, number, password, date, checkbox, radio, range, color.
<textarea>Multi-line text.
<select> / <option>Drop-down list.
<button type="submit">Button. Use type="button" to avoid submitting.
<fieldset> / <legend>Group related controls with a caption.
required min max patternBuilt-in validation attributes.

Semantic layout

<header>Introductory content or site header.
<nav>Main navigation links.
<main>Main content. Once per page.
<article>Self-contained content.
<section>Themed group of content, ideally with a heading.
<aside>Related but separate content.
<footer>Footer for the page or a section.
<details> / <summary>Collapsible block and its visible label.

Common attributes

idUnique identifier on the page.
classOne or more names, used by CSS and JavaScript.
styleInline CSS. Prefer a stylesheet.
titleTooltip text.
hiddenHides the element.
data-*Custom data, for example data-id="5".
aria-labelAccessible name when there is no visible text.

CSS

Selectors

pEvery p element.
.noteElements with class note.
#introThe element with id intro.
nav aAny a inside a nav.
ul > lili that is a direct child of ul.
h2 + pA p immediately after an h2.
a:hoverWhile the mouse is over the element.
input:focusWhile the element has keyboard focus.
li:first-childFirst child of its parent.
p:not(.note)Paragraphs that do not have class note.
.a.bElements with both classes.
a, bEither selector.

Text and colour

colorText colour. Names, hex (#3b5bdb), rgb().
backgroundBackground colour or image.
font-familyTypeface list, for example Georgia, serif.
font-size / font-weightSize and boldness.
line-heightSpace between lines. 1.5 is a good default.
text-alignleft, center, right, justify.
text-decorationunderline, none.
letter-spacingSpace between letters.

Box model

marginSpace outside the border.
paddingSpace inside the border.
borderWidth, style and colour: 1px solid #ccc.
border-radiusRounded corners.
width / heightSize of the content box. max-width is often safer.
box-sizing: border-boxWidth includes padding and border.
overflowvisible, hidden, auto, scroll.
displayblock, inline, inline-block, flex, grid, none.

Flexbox (on the parent)

display: flexStart a flex layout.
flex-directionrow or column.
justify-contentMain axis: flex-start, center, space-between, space-around.
align-itemsCross axis: stretch, center, flex-start.
flex-wrap: wrapLet items wrap onto new lines.
gapSpace between items.
flex: 1 (on a child)Let an item grow to fill space.

Grid (on the parent)

display: gridStart a grid layout.
grid-template-columnsColumn sizes, for example repeat(3, 1fr).
gapSpace between rows and columns.
grid-column: span 2Make an item cover two columns.

Units, position and responsive

px / rem / emPixels / relative to root font size / relative to parent font size.
% / vw / vhPercentage of parent / viewport width / viewport height.
position: relative | absolute | fixed | stickyHow an element is placed.
z-indexStacking order of positioned elements.
@media (max-width: 600px) { }Styles that apply only on narrow screens.
:root { --accent: #3b5bdb; }Define a custom property (variable).
color: var(--accent)Use a custom property.

JavaScript

Variables and types

const x = 1;Cannot be reassigned. Prefer this.
let y = 2;Can be reassigned.
"text" 'text'Strings. Template literals, written with backticks, allow ${x} values inside.
42 3.14Numbers.
true falseBooleans.
null / undefinedIntentionally empty / not set.
[1, 2, 3]Array.
{ name: "Ada" }Object.
typeof xThe type of a value, as a string.

Operators and conditions

+ - * / %Arithmetic. % is the remainder.
=== !==Strict equality. Use these, not ==.
< > <= >=Comparison.
&& || !And, or, not.
if (a) { } else { }Choose between paths.
cond ? a : bShort if/else that produces a value.
a ?? bUse b only when a is null or undefined.

Functions and loops

function add(a, b) { return a + b; }Function declaration.
const add = (a, b) => a + b;Arrow function.
for (const item of list) { }Loop over an array.
for (let i = 0; i < 5; i++) { }Classic counting loop.
while (cond) { }Loop while a condition is true.

Arrays

arr.lengthNumber of items.
arr.push(x) / arr.pop()Add / remove at the end.
arr.map(fn)New array with fn applied to every item.
arr.filter(fn)New array with items where fn is true.
arr.find(fn)First item where fn is true.
arr.reduce(fn, start)Combine all items into one value.
arr.includes(x)Is x in the array?
arr.join(", ")Join items into a string.
arr.splice(i, n)Remove n items from index i.

Strings

s.lengthNumber of characters.
s.toUpperCase() / s.toLowerCase()Change case.
s.trim()Remove spaces at both ends.
s.includes(x)Does it contain x?
s.split(",")Split into an array.
s.replace(a, b)Replace the first match.

The DOM and events

document.querySelector("#id")First element matching a CSS selector.
document.querySelectorAll(".x")All matching elements.
el.textContent = "hi"Set plain text. Safe.
el.classList.add("x")Add a class. Also remove and toggle.
el.style.color = "red"Set an inline style.
el.getAttribute("href")Read an attribute. Also setAttribute.
document.createElement("li")Create an element.
parent.appendChild(child)Add an element.
el.addEventListener("click", fn)Run fn when the event happens.
event.preventDefault()Stop the default action, such as a form submitting.
console.log(x)Print to the browser console.
