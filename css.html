1What is CSS?

CSS (Cascading Style Sheets) controls how HTML looks: colours, fonts, spacing and layout. A CSS rule has a selector (what to style) and declarations (how to style it), each written as property: value;.

CSS usually lives in a <style> element in the <head>, or in a separate .css file linked with <link rel="stylesheet">. These examples use <style> so everything stays in one box.

3The box model

Every element is a rectangular box made of four layers, from inside out: content, padding, border and margin. Understanding this is the key to spacing things properly.

Setting box-sizing: border-box makes width include padding and border, which is almost always what you want.

4Selectors

Selectors pick which elements a rule applies to. The most common are element (p), class (.note), id (#intro), descendant (nav a) and pseudo-class (a:hover).

Prefer classes for styling. They are reusable and do not clash with each other the way ids can.

Result
When two rules clash, the more specific selector wins. If specificity is equal, the later rule wins. That is the "cascade".

5Flexbox layout

Flexbox lays items out in a row or column. Put display: flex on the parent, then control spacing with justify-content (main axis), align-items (cross axis) and gap.

6Grid layout

Grid handles two dimensions at once. Define columns with grid-template-columns, and the browser places children into the cells. The fr unit means "a fraction of the free space".

Rule of thumb: Flexbox for a single row or column, Grid when you need rows and columns together.

7Responsive design

Pages should work on phones and desktops. First, make sure your HTML has <meta name="viewport" content="width=device-width, initial-scale=1">. Then use media queries to change styles at certain widths.
